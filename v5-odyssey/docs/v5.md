## Executive Summary

**MyPath v5.0 — Odyssey (Student Edition)** upgrades the current production app (Recipe D v4.0) into a **digital apprenticeship** for **high-school & college** students. We add:

- A **Dynamic Career Constellation** to visualize paths.  
- **Adaptive Storylines** to *try out* roles and generate behavioral evidence.  
- A **Skill Architect & Mastery Map** to close gaps with **SkillSprints**.  
- A context‑aware **Coach** (AI mentor bots; school mentors in institution mode).  
- An **Opportunity Nexus** tailored to students (clubs, scholarships, internships, campus jobs), including “**stretch**” with clear *bridge skills*.

These additions sit on top of Recipe D v4.0 without breaking existing flows, and they use **Snowflake** extensions + new **ViewModels/Services** in the current **MVVM** architecture.

---

## What’s New in v5.0 (Odyssey Phase A)

**New pillars**  
1) **Explore:** Constellation (with list fallback) + “What‑If” skill drag.  
2) **Experience:** Bite‑sized **Storylines** with consequence modeling.  
3) **Build:** **Mastery Map**, **Skill Trust Score**, **SkillSprints** (5–20 min).  
4) **Coach:** Context‑aware mentor chat (domain bots; counselor routing).  
5) **Apply:** **Opportunity Nexus** (Ready Now vs Stretch, Prepare Packs).

**Persistent:** **Action Drawer** shows top 1–3 Next Best Actions anywhere.

**Institution Mode:** guardrails for minors, school‑approved mentors, and local opportunities (clubs/programs/majors).

## Target Audiences & Modes

- **High School**  
  - Short sessions, simple language, examples from classes/clubs/volunteering.  
  - Apply tab emphasizes **clubs, competitions, scholarships, local programs**.

- **College**  
  - Deeper role realism, **internships/co‑ops**, research assistantships.  
  - Explicit **“bridge skills”** to reach stretch internships.

- **Institution Mode (Schools/Universities)**  
  - **No public networking**; route to counselors/approved mentors.  
  - Opportunities filtered by institution; **program/major mapping**.  
  - Privacy‑first defaults for minors.

Mode is determined by onboarding selections + remote config + MDM flag (if applicable).

## Feature Catalog (Phase A)

### 1) Explore — **Dynamic Career Constellation** (+ List Fallback)
- Visual map of **Career Galaxies** and **Role Stars** around user’s “Home Star.”  
- **What‑If**: drag a suggested skill onto Home Star → quick path recalculation.  
- **Role Sheet** (tap a star): overview, match breakdown (reuse current detail blocks), **“Why this role?”** chip (explainability), CTAs: **Try a Scenario** / **See Gaps**.

**Acceptance Criteria**
- Map renders ≤ 200ms after data load; List fallback always available.  
- What‑If updates show *delta time/effort* with an accessible text equivalent.

---

### 2) Experience — **Adaptive Storylines**
- Short scenario **Story Cards** → 2–3 choices → **Consequence View** with trade‑offs (time/team/ethics).  
- HS frames (club, volunteer), College frames (team assignment, internship sprint).  
- **Evidence Chip** emitted at chapter end (e.g., “Followed safety protocol L2”).  
- Optional **Future‑Self** visualization (opt‑in, action‑oriented).

**Acceptance Criteria**
- 1 scenario ≤ 3 minutes; clear reading level; VoiceOver friendly.  
- Consequences list at least 2 dimensions; “Why?” chip shows scoring rationale.

---

### 3) Build — **Skill Architect & Mastery Map**
- **Mastery Map**: current vs target skills (hard/soft/meta) with list alternative.  
- **Skill Trust Score (0–100)** with confidence indicator and decay over time.  
- **SkillSprints** (5–20 min) with adaptive checks and a tiny applied task.  
- **Project Briefs** yield artifacts → Evidence Chips.

**Acceptance Criteria**
- Skill gap view renders ≤ 300ms; Sprints store pre/post scores.  
- Mastery Map has full list alternative for accessibility/older devices.

---

### 4) Coach — **Context‑Aware Mentor**
- Upgrades **AIAssistant** to **Coach** with context chips: “Explain last decision”, “Make a plan”, “What skills help with Data Club?”  
- **Domain mentor bots** (e.g., Health, Engineering, Design).  
- Institution mode: **route to counselor/TA**, with **ice‑breaker** generator.

**Acceptance Criteria**
- Coach opens pre‑seeded with current context (screen/role) within 150ms.  
- Messages saved locally (device) unless user opts into cloud sync later.

---

### 5) Apply — **Opportunity Nexus**
- Two lanes: **Ready Now** and **Stretch** (shows **bridge skills**).  
- HS: **clubs, competitions, scholarships, local programs**.  
- College: **internships, campus jobs, research assistantships**.  
- **Prepare Pack**: resume bullets (from Evidence Chips), practice Qs derived from Storyline decisions.

**Acceptance Criteria**
- Each card shows top 2–3 fit reasons and 2–3 gap/bridge skills with one‑tap Sprints.  
- Prepare Pack compiles in ≤ 1s using cached evidence.

---

### 6) **Action Drawer** (persistent)
- Top 1–3 Next Best Actions: e.g., “Finish Active Listening (12m)”, “Join Data Club”, “Ask Coach about GPA → internship”.

**Acceptance Criteria**
- Drawer opens with a swipe or FAB ≤ 120ms; actions are deduplicated.

## User Journeys & UX Flows

### High School — 7‑Minute Loop

1. **Explore (list)** → Role Sheet: “Environmental Scientist”.
2. **Try a Scenario** → choose “ask teacher for lab safety checklist”.
3. **Consequence** explains collaboration vs autonomy.
4. **Evidence Chip** + **Next Best Action**: 10‑min “Recording Observations” Sprint.
5. **Apply** suggests Science Club + regional science fair (**bridge: data logging**).

### College — 12‑Minute Loop

1. **What‑If** drag “SQL Basics” into Constellation → Data Analyst brightens (‑20% time‑to‑impact).
2. **Storyline**: clarifies KPIs with stakeholder.
3. **Build**: gaps show “Joins + Group By”; run Sprint.
4. **Apply** reveals **stretch** internship; **Prepare Pack** builds resume bullets from Evidence.

## Algorithms & Scoring Notes

### 1) Skill Trust Score

```
trust = sigmoid(
  w1*assessment_z + w2*story_evidence + w3*project_verif + w4*mentor_endorse
  - decay(days_since_last_evidence)
)
```

* Show **confidence** (low/med/high) tied to trust & evidence freshness.

### 2) Next Best Action (NBA) Ranking

```
score(action) =
  α*goal_alignment + β*skill_gap_impact + γ*time_fit + δ*confidence_gain - ε*fatigue_cost
```

* HS prefers ≤ 20‑minute tasks; College can surface longer items.

### 3) Stretch Role Gate (Students)

* Show only if `effort_to_reach ≤ threshold` AND `bridge_skills ≤ 3` (or counselor override).

## Privacy, Safety & Ethics

* **Minors default**: no public profiles; no external DMs; anonymized `user_pid`.
* **Explainability**: “Why?” chips on roles, actions, and opportunities.
* **Bias checks**: fairness metrics on opportunity surfacing; periodic template audits.
* **Consent**: clear toggles for data sharing; local‑first storage of transcripts and evidence until accounts ship.

---

## Performance & Cost Controls

* **Constellation**: SwiftUI `Canvas`/`SpriteKit` with list fallback.
* **Storylines**: template‑driven; cache branches per user; throttle generation.
* **LLM**: domain‑scoped prompts; batched calls; aggressive memoization for repeat scenarios.
* **Offline**: pre‑bundle 3 SkillSprints; queue writes to SP_INGEST_SCENARIO_RUN.

Targets:

* API round‑trip ≤ 1.5s (parity with current).
* Constellation update ≤ 200ms after What‑If.
* Coach open ≤ 150ms with context seed.
